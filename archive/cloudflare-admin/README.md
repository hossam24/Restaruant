# Archived: the Cloudflare admin panel version

This is the first version of the owner tools: an `/admin` page backed by Cloudflare Pages Functions
and a KV store (password login, price editing, new items with photos, settings, today's orders).

It was replaced by the Google Sheet version (the owner edits the menu in a Google Sheet: no server, no password).
It is kept only for reference and is **not built or tested** any more. The paths inside it point at the old layout.
Delete this folder whenever you like.
